## Overview

Mod of Redemption is an ambitious Terraria content mod featuring a sci-fi and Lovecraftian horror aesthetic, adding multiple original biomes including an alien invasion zone and corrupted laboratory, dozens of bosses with elaborate multi-phase fight scripts, over 700 new items across all progression stages, and an original storyline woven through item lore and NPC dialogue.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Mod of Redemption** delivers the features you need in a clean, intuitive package.
